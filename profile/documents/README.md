# Profile Documents

Put optional source materials here before running `/setup`.

The setup command can read these files to generate or refresh `profile/job-profile.md`. The filtering skill does not read this folder.

This folder is intentionally free-form. You can place files directly here without creating subfolders.

Useful materials include:

- A CV or resume.
- A LinkedIn export or copied profile text.
- Portfolio notes.
- Career preferences and deal-breakers.
- Notes about target roles, technologies, work mode, locations, languages, or contract types.
- Past job postings or application notes that help calibrate what fits you.

If you prefer not to create files, you can also paste your CV, notes, or professional context directly into the `/setup` conversation.

## Privacy

Files in this folder may contain personal information and are ignored by Git by default. Keep only materials you are comfortable using locally for profile generation.
